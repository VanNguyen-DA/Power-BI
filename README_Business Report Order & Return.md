## I. Introduction

### 1. Introduction to Dataset

This project uses a global retail dataset covering multiple markets (APAC, EU, US, LATAM, Africa, Canada) and product categories (Technology, Furniture, Office Supplies). The dataset includes:

- Sales, profit, orders, customers  
- Year-over-year performance  
- Return rate  
- Market-level and category-level breakdown  
- Product-level profitability  
- Salesperson contribution  

### 2. Data Dictionary

Key fields used in the dashboard:

- **Market** — APAC, EU, US, LATAM, Africa, Canada  
- **Region / Country** — Geographic segmentation  
- **Category** — Technology, Furniture, Office Supplies  
- **Sub-Category** — Phones, Copiers, Chairs, Machines, etc.  
- **Order Date** — Transaction date  
- **Total Sales** — Revenue generated  
- **Total Profit** — Profit after cost  
- **Profit Margin** — Profit ÷ Sales  
- **Total Orders** — Number of orders  
- **Total Customers** — Unique customers  
- **IsReturned** — Return status (True/False)  
- **Product Name** — Item sold  
- **Salesperson** — Person responsible for the sale  

### 3. Business Questions

This dashboard answers critical business questions:

#### Overall Performance
- How are sales, profit, and orders trending year-over-year?
- What is the overall return rate?

#### Market Insights
- Which markets generate the highest sales and profit?
- Which regions have the strongest profit margins?

#### Category & Product Performance
- Which categories drive the most orders and profit?
- Which products and sub-categories are top performers?

#### Salesperson Contribution
- Who are the highest-margin salespeople?
- Who contributes the most profit?

#### Return Analysis
- Which categories have the highest return volume?
- How do returns impact profit?

## II. Design Thinking Method

### Step 1: Empathize
Business stakeholders require a centralized dashboard to monitor global performance, identify high-performing markets, track returns, and optimize product strategy.

### Step 2: Define
Core problem: The business lacks a single analytical view that combines sales, profit, returns, and product-level insights across all markets.

### Step 3: Ideate
Potential solutions:
- Multi-page Power BI dashboard  
- Market-level drilldowns  
- Category & product profitability visuals  
- Return rate analysis  
- Salesperson performance ranking  
- Year-over-year comparison charts  

### Step 4: Prototype
The first version of the dashboard includes:
- Business Overview page  
- Market Performance page  
- Product Performance page  
- Return Analysis page  
- Recommendation & Insights page  

### Step 5: Review
Stakeholders validated:
- KPI definitions (sales, profit, margin, return rate)  
- Visual alignment with business reporting standards  
- Layout clarity and usability  
- Final color theme and navigation
